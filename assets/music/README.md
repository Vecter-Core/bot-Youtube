# Nhạc nền

Bỏ file nhạc **không bản quyền** (.mp3, .wav, .m4a...) vào thư mục này.
Đặt tên file theo tâm trạng để AI chọn đúng, ví dụ:

- `calm_piano_1.mp3`, `lofi_chill.mp3`
- `epic_cinematic.mp3`
- `happy_upbeat.mp3`
- `mystery_dark.mp3`
- `tech_electronic.mp3`
- `inspiring_motivational.mp3`

Nguồn nhạc miễn phí: YouTube Audio Library (studio.youtube.com → Thư viện âm thanh), Pixabay Music.
Nếu thư mục trống, chương trình tự tổng hợp một đoạn nhạc nền ambient đơn giản.
